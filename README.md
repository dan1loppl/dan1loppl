## 🧠 Sobre mim

Sou um desenvolvedor **Full-Stack** focado em transformar ideias em sistemas reais, funcionais e bem estruturados.

Trabalho combinando **frontend moderno**, **backend sólido**, **bancos de dados bem modelados**, **boas práticas de arquitetura** e uma visão forte de produto.  
Meu objetivo não é apenas escrever código, mas construir experiências digitais que sejam úteis, escaláveis, performáticas e visualmente consistentes.

```txt
Produto antes da tela.
Arquitetura antes do improviso.
Experiência antes do excesso.
Código limpo antes da pressa.
```
